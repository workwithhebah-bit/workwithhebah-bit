## Featured Projects

### 1. Credit Card Fraud Detection: Cost Sensitive Machine Learning

> Fraud is only 0.17% of transactions (492 of 284,807), so a model that always says "normal" is 99.8% accurate and catches nothing. This project chooses the model by **money saved**, not by accuracy.

| | |
|---|---|
| **Models compared** | 8: Logistic Regression, Decision Tree, Random Forest, XGBoost, KNN, Naive Bayes, ANN, SVM |
| **Imbalance handling** | SMOTE on training data only, applied inside each cross validation fold to avoid leakage |
| **Tuning** | RandomizedSearchCV on all 8 models |
| **Best model** | XGBoost: precision 0.81, recall 0.87, F1 0.84 |
| **Business result** | Estimated loss of ₹2,027.93 against ₹4,262.93 for Random Forest, about **52% lower** |
| **Explainability** | SHAP, globally and for each single transaction |
| **Deployment** | Streamlit app with live predictions and SHAP explanations |
| **Stack** | Python, scikit-learn, XGBoost, imbalanced-learn, SHAP, Streamlit |

[**Repository**](https://github.com/workwithhebah-bit/credit-card-fraud-detection) &nbsp;|&nbsp; [**Live demo**](https://cost-sensitive-fraud-hebah.streamlit.app/)
